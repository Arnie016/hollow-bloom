# After the Bloom (Hollow Bloom)

Browser survival-horror prototype featuring Wren, backpack/crafting, save slots, title/pause/settings/death menus, map and notes. Release source: local commit b0e3d1a, with the packaging fix to include save.js, items.js, ui.js and map.js.

Play: https://arnie016.github.io/hollow-bloom/

Keyboard and mouse recommended. Select New Game and press Enter. Tab opens the backpack; Esc pauses. See the in-game Controls screen. Saves are stored in this browser and origin. Localhost saves do not automatically move to this URL.

AI-assisted code and generated art/audio. See CREDITS.md for asset sources. No donation/payment enabled. This is the original survival prototype, not the separate Overgrowth voxel demo; native Minecraft integration is not included in this release.

Release checks: JavaScript parse and 172 case-sensitive asset paths passed. Title/menu rendering checked locally; full campaign and device performance remain unverified for this revision.
